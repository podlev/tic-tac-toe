# Крестики-нолики

Учебный проект для мастер-класса преподавателей. Простая консольная игра «Крестики-нолики», реализованная на Python с помощью классов.

## Версии игры

- `main.py` — игра для двух игроков: первый играет за `X`, второй — за `O`;
- `computer.py` — игра с компьютером: пользователь играет за `X`, а компьютер ставит `O` в случайную свободную клетку.

## Задание

Класс `Board` хранит игровое поле 3×3 и предоставляет методы:

- `__init__()` — создаёт пустое поле;
- `__str__()` — возвращает строковое представление поля;
- `make_move(row, col, symbol)` — ставит `X` или `O` в свободную клетку;
- `check_winner(symbol)` — проверяет победу указанного игрока;
- `is_full()` — проверяет, заполнено ли поле.

Класс `Game` создаёт игровое поле, по очереди считывает ходы игроков и после каждого успешного хода выводит текущее состояние игры. Первый игрок играет за `X`, второй — за `O`.

Игроки вводят номер строки и столбца от `0` до `2`:

```text
0 0
1 0
0 1
1 1
0 2
```

Игра завершается сообщением `Победил X`, `Победил O` или `Ничья`.

## Требования

Для запуска нужен Python 3.8 или новее. Внешние библиотеки не требуются.

## Запуск

Скачайте проект и перейдите в его папку.

Игра для двух игроков:

```bash
python main.py
```

Игра с компьютером:

```bash
python computer.py
```

После запуска вводите координаты своих ходов по одной паре на каждой строке.
